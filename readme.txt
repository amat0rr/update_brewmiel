========================================================================
ДОКУМЕНТАЦІЯ ТА ПОЯСНЕННЯ ДО ВЕБ-САЙТУ "BREWMIEL" (ВЕРСІЯ: КРАФТ-ЛЮКС)
========================================================================

Цей проект представляє собою повністю готовий преміальний односторінковий 
інтернет-магазин (landing page) для бутикового гастрономічного бренду крафтових 
сиропів та меду "BREWMIEL". Код розроблений за концепцією Mobile-First 
(адаптація починається з мобільних екранів та плавно масштабується до десктопних).

СТРУКТУРА ФАЙЛІВ ПРОЕКТУ:
--------------------------
1. index.html   - Семантична структура та кістяк веб-сторінки.
2. style.css    - Стилі оформлення, адаптивна сітка медіа-запитів та плавні анімації.
3. script.js     - Інтерактивна бізнес-логіка (двомовність, кошик, нескінченна карусель).

========================================================================
1. ДЕТАЛЬНИЙ ОГЛЯД КОДУ HTML (index.html)
========================================================================
- Теги "[data-i18n]" використовуються як гачки для JavaScript. Завдяки їм текст 
  автоматично змінюється при натисканні на плаваючу кнопку зміни мови.
- Підключені шрифти преміум-серії через Google Fonts:
  * "Playfair Display" — витончений зарубковий шрифт для великих бренд-заголовків.
  * "Montserrat" — сучасний читабельний сан-сериф для інтерфейсних написів та форм.
- Інтегровані іконки через CDN-мережу "Font Awesome" (значки кошика, стрілок, видалення).
- Для картинок використані фіксовані назви за вашим технічним запитом:
  * Логотип: "logo.svg"
  * Пляшки сиропів: "png_summer.png", "png_classic.png", "png_winter.png".
  * У випадку, якщо файли ще не додані вами в папку, спрацьовує атрибут `onerror`, 
    який автоматично підставляє резервні красиві CSS-заглушки, щоб дизайн не ламався.

========================================================================
2. ДЕТАЛЬНИЙ ОГЛЯД СТИЛІВ CSS (style.css)
========================================================================
- Використовує змінні CSS (`:root`) для швидкого редагування фірмових кольорів. 
  Якщо ви захочете змінити золотий колір на інший відтінок, достатньо замінити 
  значення змінити `--gold: #D4AF37;` в одному місці на початку файлу.
- Градієнти: Основний фон створено за допомогою м'якого радіального градієнту, 
  який підсвічує центр екрану та плавно переходить у глибокий оксамитово-чорний.
- Плавність елементів: На всі кнопки, інпути та картки накладено таймінг
  `transition: all 0.4s cubic-bezier(0.25, 1, 0.5, 1);`. Це прибирає грубі переходи, 
  роблячи відгук інтерфейсу еластичним і приємним для ока.
- Анімація руху: Класи `animate-float-...` створюють ефект мікро-невагомості 
  для кориці, анісу та листочка, імітуючи дорогу 3D-динаміку без падіння FPS.
- Адаптивність: На мобільних екранах елементи шикуються один під одним, 
  меню ховається в акуратну кнопку-гамбургер. Починаючи з роздільної здатності 768px 
  і вище (@media куері), сайт перелаштовується в багатоколонковий журнальний люкс-дизайн.

========================================================================
3. ДЕТАЛЬНИЙ ОГЛЯД СЦЕНАРІЇВ JAVASCRIPT (script.js)
========================================================================
Логіка розділена на декілька автономних модулів:

А. МОДУЛЬ ЛОКАЛІЗАЦІЇ (ДВОМОВНІСТЬ)
   Об'єкт `i18n` містить паралельні переклади для UA та EN мов. Функція 
   `applyLocalization()` проходить по DOM-дереву та миттєво підміняє текстовий контент.

Б. ЦИКЛІЧНА КАРУСЕЛЬ (НЕСКІНЧЕННИЙ ЦИКЛ)
   Замість банального пересування по фіксованій лінії, тут реалізовано кругове 
   зміщення масиву `flavorsOrder = ["summer", "classic", "winter"]`. При натисканні 
   на стрілку "вправо" чи "вліво" елементи масиву циклічно переставляються місцями 
   (функції `.pop()`, `.unshift()`, `.shift()`, `.push()`). Класи CSS перепризначаються 
   динамічно. Центральна картка завжди отримує унікальне золоте підсвічування, 
   а бічні стають напівпрозорими та відходять на задній план. Карусель повністю 
   синхронізована з головним екраном (Hero-секцією).

В. ДИНАМІЧНИЙ КОШИК ТА ФОРМА ЗАМОВЛЕННЯ
   - При натисканні на кнопки "В КОШИК" або "Замовити зараз" товар потрапляє в масив `cart`.
   - Система автоматично перевіряє, чи є вже такий сироп у списку. Якщо є — збільшує 
     його кількість (`quantity`), якщо немає — створює новий рядок.
   - Кошик автоматично перераховує загальну суму в режимі реального часу.
   - Усередині бічної панелі кошика вбудовано кнопки керування кількістю (+ / -) та 
     іконку видалення (сміттєвий бак), які миттєво оновлюють стан без перезавантаження.
   - Червона точка-індикатор біля значка кошика в хідері з'являється автоматично, 
     коли в кошику є хоча б одна одиниця товару.
   - Оформлення замовлення: Валідована форма збирає дані покупця. При відправці 
     спрацьовує `e.preventDefault()`, кошик очищується, а клієнту демонструється 
     розкішне спливаюче вікно про успішне оформлення замовлення.

Г. СИСТЕМА ФІЛЬТРАЦІЇ РЕЦЕПТІВ
   Для кожного сиропу прописано по 3 унікальних авторських рецепти з інгредієнтами та 
   інструкціями приготування. При натисканні на вкладки (Tabs), JavaScript повністю 
   перемальовує сітку рецептів під обраний смак із красивим плавним ефектом підйому картки.

========================================================================
ЯК ВНЕСТИ ЗМІНИ В МАЙБУТНЬОМУ?
========================================================================
1. Зміна цін: Відкрийте `index.html`, знайдіть текст `450 ₴`, `500 ₴` або `550 ₴` 
   та пропишіть нові ціни. Також обов'язково оновіть значення в тегах кнопок 
   `data-price="..."`, щоб кошик рахував правильну математику.
2. Редагування рецептів: У файлі `script.js` знайдіть об'єкт `recipesData`. Ви можете 
   легко додати нові інгредієнти або повністю переписати інструкції як українською, 
   так і англійською мовами.
3. Додавання картинок: Просто закиньте ваші файли `logo.svg`, `png_classic.png`, 
   `png_summer.png` та `png_winter.png` в ту саму папку, де лежить файл `index.html`. 
   Резервний код автоматично розпізнає їх появу та відобразить замість заглушок.
